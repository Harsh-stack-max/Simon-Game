Simon Game

How to Play Simon Game 🎮

  • Press the "Start Game" button to begin.
  • The game will flash a color.
  • Remember the color and click the same button.
  • In the next level, a new color will be added to the sequence.
  • You must repeat the full sequence in the correct order.
  • The sequence gets longer with each level.
  • If you click the wrong color, the game will end.
  • Enjoy and for any query Contact me !!
